# قعدة ساعتك ⏱️
**على أي ساعة تعيش؟** · عيلة «تأمّل واكتشاف» في مشروع قعدة · إعداد م. إياد حلوبي

استبيان فردي مبني على مقياس زيمباردو للمنظور الزمني: 30 عبارة في 5 مراحل، والنتيجة ساعتك الداخلية بعقاربها الخمسة ونسبة توازنها، مع صورة ستوري بثلاثة أشكال.

## الملفات
| الملف | شو فيه |
|---|---|
| `public/index.html` | القعدة كاملة بملف واحد (الخطوط مضمّنة فيه، فبيشتغل حتى لو انفتح لحاله بلا إنترنت) |
| `public/manifest.webmanifest`، `public/sw.js` | تنزيل القعدة كتطبيق على الموبايل |
| `public/icon-192.png`، `public/icon-512.png` | أيقونة القعدة (للتطبيق ولصورة مشاركة الرابط) |
| `server.js` | سيرفر Express بيعرض القعدة وبيجمع الإحصائيات |
| `render.yaml` | إعداد النشر على Render |
| `Dockerfile` | للنشر بأي مكان بيدعم Docker |

## النشر على Render
1. المستودع مربوط بـ Render، فأي رفع جديد بينشر لحاله.
2. لأول مرة: New ← Blueprint ← اختار المستودع، فبيقرأ `render.yaml` لحاله وبيولّد مفتاح الإدارة `ADMIN_KEY`.

## الإحصائيات
- `/stats`: كم زيارة، كم واحد بدأ وأنهى، وأكثر ساعة طلعت.
- `/admin?key=المفتاح`: كل الأحداث (حفظ، مشاركة، تنزيل)، ونسبة الإكمال، وآخر 14 يوم. المفتاح موجود بإعدادات الخدمة على Render ← Environment ← `ADMIN_KEY`.
- أرقام بس، بلا أسماء ولا صور. الصور ما بتطلع من موبايل الشخص أبداً.

> بالخطة المجانية الإحصائيات بتنحفظ بملف جوّا السيرفر، وممكن تتصفّر عند إعادة النشر.

## رابط جاهز باسم الشخص
`https://رابط-القعدة/?n=الاسم` بيعبّي خانة الاسم مسبقاً.
