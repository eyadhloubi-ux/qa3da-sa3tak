# قعدة ساعتك ⏱️
**على أي ساعة تعيش؟** — منتج من عائلة «تأمّل واكتشاف» في مشروع قعدة · إعداد م. إياد حلوبي

- `public/index.html` — المنتج كاملاً (يعمل أيضاً كملف لوحده بالضغط عليه)
- `server.js` — سيرفر Express يعرض المنتج ويجمع الإحصائيات
- `/stats` — كم زيارة، كم واحد بدأ وأنهى، وأكثر ساعة طالعة
- `render.yaml` — إعداد النشر على Render

## النشر
1. ارفع المجلد على مستودع GitHub جديد.
2. في Render: New → Blueprint → اختر المستودع، فيقرأ `render.yaml` لوحده.

## التشغيل محلياً
```
npm install
npm start
```
ثم افتح http://localhost:3000

> الإحصائيات بالخطة المجانية تُحفظ بملف داخل السيرفر، وقد تُصفّر عند إعادة النشر.
